# Малый пилот: прогноз CRISPR-зависимости по молекулярному профилю COAD

План от 9 сентября 2026. Это гипотезы для будущих проверок, а не результаты обученных моделей.

## Рабочая цель

Предсказать CRISPR Gene Effect выбранного гена по экспрессии и мутациям новой клеточной модели. Более отрицательный Gene Effect означает более сильное снижение жизнеспособности/роста после нокаута. Это не вероятность смерти клетки или пациента. Начальная задача — регрессия; переход к меткам «сильная зависимость» требует отдельного определения порога и проверки его смысла.

Исторические CRISPR-измерения нужны как ответы для обучения и проверки. Для новой модели при предсказании используются только молекулярные признаки, без её CRISPR-данных. Нокаут и действие лекарственного ингибитора не являются взаимозаменяемыми экспериментами.

## Что уже доступно в локальных CSV

Проверены сохранённые COAD-таблицы; в экспрессии и мутациях использованы IsDefaultEntryForModel == Yes.

- 74 модели в справочнике, 66 с default-экспрессией, 48 с CRISPR, 67 с default-записями мутаций.
- Пересечение трёх молекулярных таблиц: 46 моделей и 45 групп PatientID. HCT-15 и DLD-1 имеют общий PatientID; их нельзя разносить между обучением и проверкой.
- В этом пересечении CRISPR и экспрессия KRAS, MDM2 и EGFR доступны без пропусков.
- 23 модели имеют KRAS-вариант с Hotspot=True, 22 не имеют записи варианта KRAS; ещё одна имеет только другой вариант. «Нет записи» — рабочая категория наблюдений, не подтверждённый wild-type.
- 34 модели имеют TP53-вариант с LikelyLoF=True, 11 не имеют записи варианта TP53, ещё одна имеет другой вариант без LikelyLoF. Этот флаг не доказывает функциональную инактивацию всех копий TP53.
- MSI отмечен у 10 из 46 моделей; у остальных 36 ModelSubtypeFeatures пуст. Пустое поле нельзя превратить в MSS.

## Размер пилота

1. **12 моделей, 1–2 признака, один y** — проверка ключей, флагов и графиков. Можно взять 6 моделей с KRAS hotspot и 6 без записи KRAS. Этого недостаточно для надёжной оценки обобщения.
2. **24 модели, до 5–6 признаков, один y** — первые проверки гипотез 1–3. Ориентир: 12 моделей с KRAS hotspot и 12 без записи KRAS, с учётом родства. Отбор фиксируется по признакам и доступности данных, без отбора по значениям y. Это удобный пилот, а не расчёт статистической мощности.
3. **До 46 моделей, до 10 признаков, 2–3 y** — гипотезы 4–5 и проверка устойчивости. Остаток после пилота можно использовать как небольшую отложенную проверку, если его ответы не использовались для подбора признаков и правил. В данном аудите проверялись покрытие и описательные характеристики; полностью независимое подтверждение потребует другого набора/эксперимента.

Увеличивать число измеренных моделей обычно полезнее, чем добавлять тысячи столбцов к двум десяткам строк. Полную матрицу из 55 тысяч столбцов для этого пилота загружать в ML не требуется.

## Гипотеза 1. Статус KRAS помогает предсказывать зависимость от нокаута KRAS

**Формулировка:** модели с зарегистрированным hotspot-вариантом KRAS имеют в среднем более отрицательный KRAS Gene Effect, чем модели без зарегистрированного варианта KRAS.

- X: один бинарный признак KRAS_hotspot. Не использовать общий mut__KRAS как синоним активирующего варианта: он отмечает любую запись мутации.
- y: KRAS (3845) из CRISPR.
- Первая проверка: точки для всех моделей, разность средних эффектов между двумя группами и интервал неопределённости с учётом PatientID.
- Предиктивная проверка: предсказание по среднему своей группы, вычисленному только на train, против общего среднего train. Основная ошибка — RMSE, дополнительно MAE.
- Поддержка гипотезы: отрицательная разность между группами и уменьшение ошибки на моделях, не участвовавших в подгонке. Широкий интервал, включающий ноль, означает неопределённость, а не доказанное отсутствие связи.

Это воспроизведение ожидаемой связи для проверки подхода. KRAS-зависимость встречается и без активирующих мутаций; мутационный флаг не является полным объяснением. Источник: [Ulmer et al., 2022](https://www.nature.com/articles/s41540-021-00211-8).

## Гипотеза 2. Несколько значений экспрессии позволяют предсказывать KRAS Gene Effect

**Формулировка:** небольшая заранее выбранная панель экспрессии даёт меньшую ошибку прогноза KRAS Gene Effect, чем одинаковый прогноз для всех моделей.

- X: сначала только экспрессия KRAS; затем фиксированная панель KRAS, EGFR, DUSP6, ETV4, SPRY2. Все столбцы есть в локальном файле. Эта маленькая панель — предложенная проверяемая конструкция, не валидированная сигнатура.
- y: KRAS Gene Effect.
- Метод: линейная регрессия для одного признака; Ridge для пяти. Не подбирать направление связи по интуиции «выше экспрессия — обязательно сильнее зависимость».
- Сравнение: baseline со средним train, модель с одной экспрессией, модель с пятью экспрессиями; одинаковые разбиения.
- Поддержка: меньшая ошибка на отложенных моделях, воспроизводимая по разбиениям и не обусловленная одной строкой.

Предсказание KRAS-зависимости по экспрессии имеет исследовательское основание, однако результат больших исследований не гарантирует успех именно пяти генов в 24 COAD-моделях. [Исследование KRAS-зависимости и экспрессионных моделей](https://www.nature.com/articles/s41540-021-00211-8).

## Гипотеза 3. Мутации и экспрессия содержат дополнительную друг к другу информацию

**Формулировка:** объединение KRAS_hotspot и пяти экспрессионных признаков предсказывает KRAS Gene Effect лучше каждого блока отдельно.

- X: один мутационный флаг + пять значений экспрессии.
- y: KRAS Gene Effect.
- Сравнить три заранее заданных варианта: только мутация; только экспрессия; оба блока.
- Использовать одни и те же модели, разбиения и сопоставимые линейные методы. Выбор регуляризации, если он нужен, выполнять внутри train.
- Поддержка: положительное снижение ошибки относительно ОБОИХ отдельных вариантов на общих отложенных предсказаниях. Интервал разности ошибок важнее небольшого выигрыша в одной попытке.

Если объединение не улучшает результат, это полезный результат пилота: дополнительные данные пока не оправдали усложнение. Возможны избыточность признаков, недостаток наблюдений или слабый сигнал выбранной панели.

## Гипотеза 4. Мутационное состояние одного гена связано с зависимостью от другого

**Биологическая формулировка:** потеря функции TP53 ослабляет зависимость от MDM2, который участвует в подавлении p53. Проверяем перенос этого ожидания на COAD, а не считаем его заранее доказанным.

**Операциональная формулировка для этих файлов:** модели с TP53 LikelyLoF имеют менее отрицательный MDM2 Gene Effect, чем модели без зарегистрированного варианта TP53.

- X: статус TP53 по исходным аннотациям. Модель с другим вариантом TP53 анализировать отдельно/исключить из первоначального двухгруппового сравнения.
- y: MDM2 (4193) из CRISPR.
- Лучше использовать доступные 34 против 11 моделей, чем искусственно уменьшать небольшую группу сравнения.
- Первая проверка: график распределений и разность средних, ожидаемое направление — ближе к нулю у группы LikelyLoF.
- Предиктивная проверка: групповой прогноз по TP53 против общего среднего train.

LikelyLoF и отсутствие записи — несовершенные заменители функционального статуса p53. Поэтому первый результат будет ассоциацией аннотации с ответом, а не доказательством механизма. Биологическую интерпретацию нужно подтвердить уточнением вариантов/статуса. Есть также влияние TP53 на ответ на разрезы Cas9, которое важно учитывать при дальнейшем анализе.

Основание: [Stolte et al., 2018 — зависимости p53-пути в других опухолевых моделях](https://pubmed.ncbi.nlm.nih.gov/30045945/). Ограничение интерпретации CRISPR: [TP53-dependent toxicity of CRISPR/Cas9 cuts](https://www.nature.com/articles/s41467-022-32285-1).

## Гипотеза 5. По профилю модели можно выбрать наиболее сильную из нескольких уязвимостей

**Формулировка:** индивидуальные прогнозы выбирают наиболее сильный нокаут среди KRAS, MDM2 и EGFR лучше, чем один общий рейтинг этих генов для всех моделей.

- X: максимум десять признаков — экспрессия KRAS, EGFR, DUSP6, ETV4, SPRY2, TP53, MDM2, CDKN1A плюс KRAS_hotspot и TP53_LikelyLoF.
- y: три CRISPR Gene Effect. На первом этапе — отдельная простая регрессионная модель для каждого гена.
- На каждой отложенной модели выбрать ген с самым отрицательным предсказанным эффектом.
- Baseline: одинаковый для всех рейтинг по среднему эффекту каждого гена на train. Сравнение только со случайным выбором недостаточно.
- Метрики: доля совпадений выбранного гена с фактически самым отрицательным и regret = фактический Gene Effect выбранного гена минус минимальный фактический Gene Effect среди трёх. Меньше regret — лучше.
- Поддержка: меньший regret и устойчивое преимущество над общим рейтингом. При почти одинаковых фактических эффектах точное попадание в top-1 малоинформативно.

46 моделей × 3 гена не превращаются в 138 независимых моделей. Все ответы одной модели и родственные линии должны оставаться в одной части разбиения. Успех этой гипотезы относится к выбору среди трёх фиксированных генов; он ещё не подтверждает поиск уязвимости среди всего генома.

## Общие правила оценки

- Зафиксировать гипотезы, признаки, основной критерий и разбиения до перебора результатов.
- Для 24 моделей использовать групповую перекрёстную проверку, например 4 блока по PatientID. Отдельный тест из 4–5 строк слишком неустойчив для основных выводов.
- Пропуски X заполнять и значения масштабировать только внутри train. Целевые пропуски не импутировать. Другие CRISPR-столбцы не включать в X при заявленной цели без CRISPR для новой модели.
- Считать общее качество по отложенным предсказаниям; показывать также ошибки отдельных моделей и неопределённость разности с baseline. Блоки перекрёстной проверки не являются независимыми повторными экспериментами.
- На небольшом наборе использовать интервалы с пересэмплированием групп и, при необходимости, перестановочную проверку всего процесса. Если сообщаются p-values по нескольким гипотезам, учитывать множественные проверки.
- Избегать перебора тысяч пар «признак–мишень» с последующим отчётом только лучшей. Отрицательный результат одной гипотезы не опровергает возможность предсказания других зависимостей.
- После фиксации подхода: расширить число моделей, затем число мишеней, затем панель признаков. Для независимого подтверждения использовать другой источник/набор моделей; учитывать повторяющиеся линии между выпусками.

## Почему WRN–MSI не входит в первые пять

Связь MSI с зависимостью от WRN — сильный кандидат для следующего этапа, известный из [исследования Chan et al., 2019](https://www.nature.com/articles/s41586-019-1102-x). Но сейчас есть только 10 положительных отметок MSI и 36 неизвестных. Сначала нужны достоверные MSI/MSS-аннотации; неизвестные нельзя объявлять MSS. После этого связь можно использовать как дополнительную проверку известного биологического сигнала.
